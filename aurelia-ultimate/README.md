# Aurelia Ultimate — Aventura de Criaturas

RPG de exploración, combates por turnos y captura de criaturas para el navegador. Arte, música, textos y criaturas **originales**
(generados por código). Sin dependencias en ejecución, sin servidores, sin servicios de pago.

> Estado: **Fase 1 completa y probada** (ver `docs/PROGRESO.md`). Las siguientes fases se van añadiendo sobre esta base.

## Jugar
Abre `index.html` con doble clic, o desde una terminal: `python3 -m http.server 8080` y visita <http://localhost:8080>.

## Desarrollo
```bash
npm install        # solo esbuild (herramienta de empaquetado)
npm run build      # genera dist/game.js
npm test           # pruebas del núcleo (Node)
```
